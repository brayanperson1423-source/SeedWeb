# Instalar un cliente en 1 día

## Antes (30 min)
- [ ] Confirmar nicho y micro app contratada
- [ ] Recibir logo, nombre, datos de contacto y colores
- [ ] Recibir lista de productos/servicios con precios (CSV, Excel o foto)
- [ ] Firmar términos del servicio y acuerdo de tratamiento de datos

## Instalación (2 a 4 h)
- [ ] Crear el negocio y el usuario dueño
- [ ] Activar el paquete de nicho
- [ ] Configurar marca (logo, colores, nombre)
- [ ] Importar el catálogo y revisarlo con el cliente
- [ ] Probar una cotización completa y enviarla por WhatsApp al propio dueño

## Entrega (30 min)
- [ ] Mostrar al dueño cómo abrir el enlace y agregarlo a la pantalla de inicio
- [ ] Capacitar a los empleados que lo usarán
- [ ] Entregar manual de una página
- [ ] Acordar fecha de revisión a los 7 días

## Seguimiento
- [ ] Día 7: revisar uso y dudas
- [ ] Día 14: mostrar resultados medibles (tiempo ahorrado, cotizaciones enviadas)
- [ ] Día 14: pedir cierre de la mensualidad y dos referidos
