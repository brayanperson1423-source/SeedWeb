# Checklist antes de mostrar o entregar a un cliente

## Producto
- [ ] Funciona en celular (~375 px) y en computador
- [ ] Estados vacíos y errores con mensajes claros en español
- [ ] Totales calculados correctamente (pruebas pasando)
- [ ] PDF con marca del negocio se ve bien
- [ ] Enlace de WhatsApp abre con el mensaje correcto
- [ ] Se puede agregar a la pantalla de inicio (PWA)

## Seguridad y datos
- [ ] Probado con 2 negocios: ninguno ve datos del otro
- [ ] Sin secretos en el repositorio
- [ ] Copias de seguridad configuradas
- [ ] El cliente puede exportar sus datos

## Legal (revisar con un abogado)
- [ ] Política de tratamiento de datos publicada
- [ ] Autorización de datos de los clientes finales
- [ ] Términos del servicio y acuerdo de tratamiento de datos firmados

## Comercial
- [ ] Precio y condiciones acordados por escrito
- [ ] Fecha de revisión a los 7 días agendada
